# Adam shop photo pack (wired slots)

SVG wrappers with embedded JPEG data-URIs for slots wired into the site.
GitHub MCP cannot upload raw binary JPEGs (verified: base64 content is stored as ASCII text).

Wired: hero, case-lizards, case-amphibians/red-eyed, day-gecko, gecko macro, whites, tan-eared, dyeing-dart, azureus fallback.
Gaps: snake-handle door, storefront, case-row, snakes (existing assets kept). Extra pack photos omitted from this PR for MCP payload size; available locally in web2/.
